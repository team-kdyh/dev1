# Project 작업 규칙

- 사용자가 직접 바꾼 유닛 체력·공격력·가격·사거리 등 밸런스 수치는 의도된 변경으로 취급한다.
- `Assets/Scripts/Sim/M0Balance.cs`의 수치를 명세서나 이전 기본값과 다르다는 이유로 되돌리지 않는다. 스탯 변경 요청이 있을 때만 조정한다.
- 밸런스 변경으로 기존 테스트가 실패하면 변경된 규칙을 먼저 확인한다. 테스트를 통과시키려고 사용자 수치를 원복하지 않는다.
- 현재 범위는 세미콘 9종과 오차드 9종의 스탯·생산·이동·단일 대상 기본 공격, 워치 메딕 회복, 공통 상태 저장 구조와 임시 생산 UI이다. 기본 대전은 P0 세미콘/P1 오차드이며, 나머지 고유 스킬·시대 해금은 별도 요청 전까지 추가하지 않는다.
