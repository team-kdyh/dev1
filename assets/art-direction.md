# 제품 유닛·인물 보스 2D 아트 방향

**기준:** `my spec.md` §2~4의 프레임 규격과 사용자 지정 새 디자인 방향. 팀의 인게임 검수 후 형태를 최종 확정한다.

T1~T8은 제품 사진의 형태를 유지한 채 색면을 살짝 단순화하고 얇은 윤곽선·팔다리·전투 표정을 붙인다. T9는 제품 사진 없이 이재용·스티브 잡스의 캐리커처 얼굴과 그린 인물 몸으로 만든다. [세미콘 라인업](concepts/semicon-lineup.png), [오차드 라인업](concepts/orchard-lineup.png), [애니메이션 시트](previews/unit-art-contact-sheet.png)를 확인한다. 사진 원본과 출처는 [제품 사진 출처](source/product-photos/sources.json), [보스 얼굴 기록](source/boss-portraits/README.md)에 있다.

## 공통 규칙

- **일반 유닛:** 제품 사진을 배경에서 분리한 뒤 채도·명암을 조금 높이고 색 단계를 줄이며 2px 안팎 윤곽선을 입힌다. 카메라·힌지·화면처럼 제품을 알아보게 하는 형태는 유지한다.
- **팔다리:** 제품 뒤에 흰색 중심선과 검은 테두리의 팔, 흰 손, 검은 발을 배치한다. 상태별로 팔다리와 본체 위치를 조금씩 움직인다.
- **표정:** 모든 일반 유닛의 제품 표면에 찡그린 눈썹과 눈·입을 직접 얹는다. 눈썹·입의 밝은 외곽선으로 화면 사진과 대비를 만들며 별도 네모 바탕은 쓰지 않는다. 공격·스킬 중에는 더 크게 외치고, 사망 시에는 X자 눈으로 바뀐다.
- **크기:** T1~T6은 128px, T7~T9는 192px 투명 프레임이다. 실제 전투 화면 배율에서 식별성을 확인해야 한다.
- **보스:** T9는 이재용의 각진 눈썹·안경·정장·파란 넥타이, 스티브 잡스의 높은 이마·둥근 안경·수염·검은 상의를 사용한다. 얼굴은 이를 드러내는 전투적인 캐리커처로 그리며 제품 이미지는 넣지 않는다.

## 임시 상태 표현 제안

| 시뮬 데이터 | M0~M1 임시 표시 | M2 정식 에셋 |
| --- | --- | --- |
| `stun` | idle + 노란 틴트/별 | 회전 별, 채도 감소 |
| `silence` | 상단 X 표시 | 전용 침묵 아이콘/파동 |
| `slow` | 청색 틴트 | 발밑 얼음/점성 |
| `malfunction` | 깜박임 | 글리치 노이즈 |
| `charm` | 테두리 진영색 변경 | 골드 파티클 포함 |
| `folded/unfolded` | 두 클립 제공 | 서로 다른 정식 실루엣 |
| `ghost` | 투명도 50% | 반투명/잔상 |
| 과열 1~5 | 적색 발광 강도 단계 | 단계별 장비·파티클 변화 |

임시 표시의 실제 구현 주체는 A 렌더이며, D는 필요한 키·이미지·색을 제공한다. B의 데이터 필드가 확정된 뒤 대응표를 갱신한다.
