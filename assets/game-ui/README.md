# 전투 UI 생성 이미지

2026-10-04에 내장 `imagegen`으로 만든 투명 배경 PNG 네 장이다. 두 성은 제품의 카메라 배치를 크게 남겨 진영을 구별하고, 얼굴 표정과 두꺼운 검은 외곽선을 얹었다. 유닛 카드의 중앙은 기존 캐릭터 아틀라스를 놓기 위해 비워 두었다.

| 파일 | 제작 브리프 |
| --- | --- |
| `semicon-base.png` | 단순한 2D 횡스크롤 전투 게임용 삼성 갤럭시 형태의 은색 스마트폰 성. 세로로 나란한 카메라 세 개, 전투적인 눈썹과 표정, 파란 성벽과 파란 깃발, 두꺼운 검은 손그림 윤곽, 정면 전체 모습, 투명 배경, 글자와 사람 없음. |
| `orchard-base.png` | 삼성 성과 같은 크기와 구도의 애플 아이폰 형태의 흰색 스마트폰 성. 삼각형 카메라 배치, 전투적인 표정, 코럴색 성벽과 깃발, 두꺼운 검은 손그림 윤곽, 정면 전체 모습, 투명 배경, 글자와 사람 없음. |
| `semicon-unit-card.png` | 작은 모바일 생산 버튼을 위한 단순한 만화풍 세로 카드. 아이보리색 빈 캐릭터 창, 거친 검은 윤곽, 파란 가격 명패, 투명 바깥 여백, 글자와 캐릭터 없음. |
| `orchard-unit-card.png` | 삼성 카드와 동일한 형태의 생산 버튼. 가격 명패만 코럴색으로 바꾸고 아이보리색 빈 캐릭터 창과 투명 바깥 여백을 유지. |

`src/render/textures.ts`가 성과 카드 텍스처를 불러온다. 카드의 생성 이미지 바깥 투명 여백은 텍스처 프레임에서 제외한다. `src/render/BaseView.ts`가 성 이미지, 진영명과 체력 막대를 놓고, `src/ui/UnitButton.ts`가 카드 위에 기존 유닛 아틀라스 프레임과 가격을 올린다. 배포 시 `tools/copy-runtime-assets.mjs`가 네 PNG를 `dist/assets/game-ui/`로 복사한다.
