# 전투 표현 규칙

기준일: 2026-09-26

## 공격 방식

| 조건 | 표현 | 판정 시점 |
| --- | --- | --- |
| 이어버드 근접 | 캐릭터 attack 클립과 동심원 음파 | 공격 동작 시 즉시 |
| 워치 | 심박 파형 / 피트니스 링 | 투사체가 대상에 도착할 때 |
| 폰 | 데이터 패킷 / 생태계 궤도 / 카메라 렌즈 빔 | 투사체가 대상에 도착할 때 |
| 태블릿·헤드셋 | 펜 투척 / 공간 컴퓨팅 고글 | 투사체가 대상에 도착할 때 |
| 노트북·AI·궁극 유닛 | 창 격자, 에어 슬라이스, 열파, AI 노드, 지시 화살표, 키노트 카드 | 투사체가 대상에 도착할 때 |
| 폴드·패드 탱커 | 힌지 충격파 / 펜 휘두르기와 돌진 | 공격 동작 시 즉시 |
| 4번째 공격 | cast 클립과 큰 스킬 에너지탄, 피해 1.55배 | 근접은 즉시, 원거리는 착탄 시 |

공격 간격은 C 밸런스의 `atkSpeed`에서 계산한다. 일반 피해는 `DPS × 공격 간격`으로 계산하므로 기존 공격력·공격 속도 조합을 유지한다. 치명타는 기존 데모 규칙인 12% 확률과 2배 피해를 유지한다.

논리 좌표 1이 화면 4px로 보이는 점을 기준으로 전 유닛의 교전 거리를 다시 조정했다. 일반 전열은 14~34, 중거리 제어 유닛은 36~50, 저격·공성 유닛은 52~75이며 현재 최장 사거리는 북 워크스테이션의 75다. 기지 공격은 건물 외곽에서 멈추도록 별도의 최소 접근 거리를 사용한다.

웹 전투 데모의 기본 시간 배율은 `0.72`로 낮춰 이동·생산·공격 흐름이 함께 느려지도록 했다. 전장 캐릭터 높이는 기존보다 약 18~20% 키우고, 같은 편 대열 간격과 5개 시각 레인의 간격도 함께 넓혀 큰 캐릭터가 과도하게 겹치지 않게 했다.

## 방어와 피격

- `tank` 역할은 55%, 나머지 유닛은 8% 확률로 공격을 막는다.
- 방어 성공 시 최종 피해는 원래 피해의 35%이며 파란 방패 링, 뒤로 버티는 자세, 방어 색상이 표시된다.
- 세미콘 폴드 방패병은 D의 `folded` 클립을 방어 자세로 사용한다. 전용 클립이 없는 캐릭터는 idle 프레임과 코드 기반 버티기 동작을 함께 사용한다.
- 폴드 방패병과 패드 방패병의 공격에는 별도 힘 모으기, 방패 돌진, 진영별 힌지/펜 타격 궤적, 복귀 동작을 적용한다.
- 일반 피격은 붉은 플래시와 짧은 넉백으로 표현한다.

## 효과음과 BGM

- `attack`, `skill`, `kill` 이벤트는 해당 유닛의 공격·스킬·사망 OGG를 재생한다.
- `baseHit`, `ageup`, `rejected`, `gameOver`, T9 등장도 D의 공통 효과음을 사용한다.
- BGM은 플레이어 진영 음악을 사용한다. Age 1은 `bass_drums`, Age 2는 `synth`, Age 3은 `strings`를 더하며 Age 4에서는 `age4` 전용 트랙으로 전환한다.
- BGM 합산 볼륨은 0.5 이하, 효과음은 종류에 따라 0.25~0.52로 제한한다. 같은 유닛 효과음은 최대 4채널까지 겹쳐 재생한다.
- 브라우저가 OGG/Vorbis를 지원하면 OGG를 우선하고, 지원하지 않으면 MP3 파일로 자동 대체한다.

## 현재 범위

이번 구현은 전투를 읽기 쉽게 만드는 기기별 공격·방어·강화 스킬 표현이다. C 데이터에 정의된 개별 스킬의 회복, 소환, 침묵, 광역 버프 같은 고유 판정은 아직 `FakeSimAdapter`에 들어 있지 않다. 이 규칙은 B 시뮬레이션 연결 전까지 사용할 웹 전투 데모 기준이다.

양쪽 본진은 공용 빌딩 대신 세미콘의 폴더블 성문·웨이퍼 코어·S펜 포대가 달린 `GALAXY FAB`, 오차드의 원형 캠퍼스·유리 큐브·MagSafe 링이 결합된 `INFINITE LOOP`로 구분한다. 두 기지의 코어는 진영별 방향으로 회전하고 시대 상승 시 함께 커진다.

전투를 가리던 화면 중앙의 생산 대기열은 HUD에서 제거했다. 생산 자체와 최대 대기열 판정은 유지되지만, 화면에서 대기열을 클릭해 취소하는 기능은 제공하지 않는다.
