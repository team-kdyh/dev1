# PvE 출시 준비 점검 · 2026-10-04

## 확인한 기능

- 캠페인 24개 스테이지, 빠른 대전, 도감, 연구소, 설정, 전투 결과 화면이 연결되어 있다.
- 18개 캐릭터의 아틀라스 애니메이션, 67개 효과음과 8개 BGM 항목을 검증한다. 진영별 생성 이미지 성 2개와 생산 카드 2개를 연결했다. `npm run build`는 실행에 필요한 정적 파일 180개(16.9 MiB)를 `dist/assets`로 복사한다.
- 전투 시뮬레이션은 승리·패배·무승부, 단계별 적 수치·보스 등장, 주요 유닛 능력, 진행 저장 실패 처리, 캠페인 초반 전투 안내를 지원한다. 아군 유닛은 같은 위치에서 출격·교전할 수 있고, 이동과 시대별 수급이 빨라졌다.
- `npm run check`: 밸런스 파일 15개 검사 오류 0건, 타입 검사 통과, 테스트 40개 통과, 웹 게임·편집기 빌드 성공. `python3 assets/tools/validate_assets.py`: 18개 유닛, 원본·아틀라스 각 444프레임, 4개 아틀라스, 오디오 논리 키 검증 통과.
- Chrome에서 배포 빌드의 데스크톱 메뉴·전투·양 진영 성·선택 화면과 390px 모바일 생산 카드를 확인했고 런타임 예외는 없었다. 이전 모바일 캠페인·양 진영 전투·일시정지 검수도 통과했다.

## 출시 전 남은 기준

| 영역 | 현재 측정·상태 | 완료 조건 |
| --- | --- | --- |
| 전투 밸런스 | 기본 성 체력 5,000→3,000, 일반 대전 300→240초로 변경했다. 40개 고정 시드의 T1/T3 반복 전략 vs 보통 AI에서 삼성 31승·평균 180초, 애플 39승·평균 93초다. 어려움 AI에서는 삼성 0승·164초, 애플 8승·229초다. 첫 교전은 각각 평균 3.9초·4.1초다. | 사람 플레이와 여러 전략으로 진영 간 승률과 실제 체감 시간을 다시 측정한다. 한 반복 전략의 큰 진영 차이를 우선 검토하고, 명세 §17의 기존 평균 4~8분 목표를 빠른 전투 요구에 맞춰 팀에서 갱신한다. 이 도구의 수치를 전체 승률로 해석하지 않는다. |
| 시대 진행 | 어려움 AI의 Age 2 첫 진입 평균은 삼성 상대 62초, 애플 상대 68초이고, Age 3은 각각 112초·140초다. 시대 상승 비용과 누적 수급 조건을 낮추고 새 시대마다 초당 수급을 4씩 올렸다. | 짧아진 성 파괴 시간 안에서 후기 유닛을 쓸 수 있는지 사람 플레이와 여러 전략에서 측정하고 시대별 체류 시간을 조정한다. |
| 캠페인 검수 | 시작·전투·저장 경로와 보스 스폰은 자동 및 브라우저에서 일부 확인했다. | 24개 스테이지를 각각 실제 플레이해 승리 조건, 난이도, 보상·잠금 해제, 작은 화면 조작을 확인. |
| 공개 배포 콘텐츠 | 게임 화면은 실제 기업명과 인물을 다루며, 명세 §16은 상표·초상 사용을 공개 배포 전 해결할 위험으로 기록한다. | 팀이 사용할 명칭·이미지·음원의 배포 권한을 검토하고 공개본을 확정. |
| 온라인 대전 | 미구현이라 PvE 메뉴에서 숨겼다. | PvP를 출시 범위에 포함할 때 서버 권위 시뮬레이션, 결정론·동기화 검증, 매칭과 리플레이를 별도로 완료. |

현재 `dist/`는 팀 내부 시연과 PvE 테스트용으로 실행할 수 있다. 정식 공개 출시 판정은 위 항목을 확인한 뒤 내린다.
