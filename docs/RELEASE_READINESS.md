# PvE 출시 준비 점검 · 2026-10-04

## 확인한 기능

- 캠페인 24개 스테이지, 빠른 대전, 도감, 연구소, 설정, 전투 결과 화면이 연결되어 있다.
- 18개 캐릭터의 아틀라스 애니메이션, 67개 효과음과 8개 BGM 항목을 검증한다. `npm run build`는 실행에 필요한 정적 파일 176개(14.2 MiB)를 `dist/assets`로 복사한다.
- 전투 시뮬레이션은 승리·패배·무승부, 단계별 적 수치·보스 등장, 주요 유닛 능력, 진행 저장 실패 처리, 캠페인 초반 전투 안내를 지원한다. 아군 유닛은 같은 위치에서 출격·교전할 수 있고, 이동과 시대별 수급이 빨라졌다.
- `npm run check`: 밸런스 파일 15개 검사 오류 0건, 타입 검사 통과, 테스트 40개 통과, 웹 게임·편집기 빌드 성공. `python3 assets/tools/validate_assets.py`: 18개 유닛, 원본·아틀라스 각 444프레임, 4개 아틀라스, 오디오 논리 키 검증 통과.
- Chrome에서 배포 빌드의 캠페인 시작, 전투 안내 완료, 일시정지까지 직접 확인했고 런타임 예외는 없었다.

| 영역 | 현재 측정·상태 | 완료 조건 |

| 전투 밸런스 | `npm run audit:pve -- --matches=40 --difficulty=hard` 고정 시드에서 T1/T3 반복 전략 승률은 두 진영 모두 0/40. 첫 교전 평균은 세미콘 3.9초, 오차드 4.1초다. 평균 전투 길이는 각각 222초·231초이며 모든 판이 본진 파괴로 끝났다. | 사람 플레이와 여러 전략을 포함해 명세 §17의 평균 4~8분, 진영 승률 45~55%, 단일 유닛 반복 전략 40% 미만을 검증하고 조정. 이 도구의 한 전략 결과를 전체 승률로 해석하지 않는다. |
| 시대 진행 | 같은 실험에서 적 AI의 Age 2 첫 진입 평균은 세미콘 상대 62초, 오차드 상대 68초이고, Age 3은 각각 112초·107초다. 시대 상승 비용과 누적 수급 조건을 낮추고 새 시대마다 초당 수급을 4씩 올렸다. | 빨라진 전투 길이에 맞는 시대별 체류 시간을 사람 플레이와 여러 전략에서 측정하고, 명세 §17의 기존 Age 2 60~90초·Age 3 150~210초 목표를 조정할지 팀에서 결정. |
| 캠페인 검수 | 시작·전투·저장 경로와 보스 스폰은 자동 및 브라우저에서 일부 확인했다. | 24개 스테이지를 각각 실제 플레이해 승리 조건, 난이도, 보상·잠금 해제, 작은 화면 조작을 확인. |
