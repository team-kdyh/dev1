# 기기별 전투 정체성

기준일: 2026-09-26

현재 웹 데모는 아래의 기본 공격 실루엣을 구현했다. `FakeSimAdapter`의 공통 피해 판정은 유지하며, 효과 열의 내용은 B 시뮬레이션 연결 시 적용할 후속 아이디어다.

| 유닛 | 현재 공격 표현 | 후속 고유 효과 아이디어 |

| 버즈 트윈스 | 겹쳐 퍼지는 방향성 음파 | 두 개체가 생존하면 음파가 교차해 추가 피해 |
| 워치 메딕 | 심장과 심전도 파형 | 적 공격 시 가장 약한 아군에게 소량 회복 전송 |
| A폰 보병 | 화면 모양 데이터 패킷 | 근처 A폰 수에 따라 패킷이 하나씩 증가 |
| S폰 저격수 | 카메라 렌즈 레이저 | 조준 시간이 길수록 줌 배율과 치명타 증가 |

| 탭 포병 | 회전하며 날아가는 S펜 | 착탄 후 펜이 지면을 그어 잠시 위험 구역 생성 |

## 기지

- `GALAXY FAB`: 폴더블 성문, 반도체 회로, 웨이퍼 코어, S펜 포대. 저체력에는 붉은 회로 균열이 점멸한다.
- `INFINITE LOOP`: 원형 캠퍼스, 유리 큐브, MagSafe 코어, 프레젠테이션 비콘. 저체력에는 배터리 부족 경고가 점멸한다.
- 두 코어는 반대 방향으로 회전하고 시대 상승 시 건물과 함께 커진다.
